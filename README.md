# Facial Emotion Recognition for Enhancing E-Learning Environment

A deep learning-based engagement detection system using EfficientNet-B2 and the DAiSEE dataset. The project predicts student engagement levels from facial expressions to enhance online learning environments.

## Live Demo

Streamlit App: https://engagement-app-kvpqxadb2bcbdg5qnautz4.streamlit.app/

## Features

- Real-time engagement detection
- Face detection using OpenCV
- EfficientNet-B2 deep learning model
- Streamlit web application
- DAiSEE dataset integration

## Tech Stack

- Python
- PyTorch
- Streamlit
- OpenCV
- EfficientNet-B2
